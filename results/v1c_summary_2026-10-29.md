**Fare-rule subset (n=88):** best is Opus + cite + guide, F1 77.2 [72.7-81.8] and action 87.5, vs rule-based 44.5.

**Policy-text subset (n=44):**
- Wide CIs, and guidelines don't help (Opus 67.8 vs + guide 67.8).
- The guide was written for fare rules, so the guidelines effect is fare-rule specific.

**Paired bootstrap (2,000 resamples, all_dedup):**
- **LLM vs rules:** Opus − rule-based F1 +17.1 [+10.6, +23.1], recall +31.8.
- **Citation constraint:**
  - Opus: F1 +4.1 [+1.3, +6.9]; precision +9.4; recall **−3.4 [−6.4, −0.5]**.
  - Sonnet: F1 +4.1 [+1.4, +6.7]; precision +15.1; recall **−7.7 [−10.9, −4.7]**.
- **Chunk context:**
  - Opus: +0.8 (n.s.).
  - Sonnet: +2.8 [−0.0, +5.8] (borderline); recall +4.7; action +10.6.
- **Guidelines:**
  - Opus: +6.8 [+3.2, +10.4]; action +13.6.
  - Opus with citations: +5.6 [+2.4, +9.3]; action +19.7.
- **Opus vs Sonnet:** F1 +2.1 (n.s.); recall +4.7; action +12.9.

**Correction to the v1b narrative:** on the larger set the citation constraint's recall cost on Opus becomes significant (−3.4). The claim is therefore *"grounding trades a small recall loss for a large precision gain; the loss is about half as large for the stronger model (−3.4 vs −7.7)"*, NOT *"grounding is free"*.
